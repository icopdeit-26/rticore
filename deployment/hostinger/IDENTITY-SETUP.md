# Independent identity gateway — staging templates only
Use separate Keycloak PostgreSQL database and credentials, TLS hostname, no public admin console. Import realm template after replacing example.invalid hosts. Create confidential proxy client secret and configure OAUTH2_PROXY_CLIENT_SECRET and OAUTH2_PROXY_COOKIE_SECRET outside git. Set RTICORE_OIDC_ISSUER, RTICORE_OIDC_CLIENT_ID and RTICORE_OIDC_AUDIENCE to match. Require Keycloak browser flow MFA (OTP or WebAuthn) for every enrolled user; the realm template alone does NOT enforce MFA. Disable untrusted email changes and verify existing account ownership before enrollment. Bind Node and proxy to loopback. Nginx overwrites incoming token header; only signed access token from auth_request is forwarded. Test valid session, anonymous denial, forged header, expired token, refresh cookies, CSRF, logout and direct-origin access. Nginx 401 behavior and refreshed/split cookies require staging browser validation. Proxy logout alone does not revoke IdP sessions; WP05 remains open. Do not deploy or activate Finance until security and operational gates pass. Templates are uninstalled and unvalidated against actual server versions.
