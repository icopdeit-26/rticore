## Security choices and limits
Node built-in scrypt (N=32768,r=8,p=3), AES-256-GCM protected TOTP seed bound to email, 256-bit opaque sessions stored as SHA-256 hashes, Secure HttpOnly SameSite=Strict cookie, exact Origin mutation checks, 30-minute idle/8-hour absolute TTL. scrypt selected to avoid native addon compatibility risk; load test CPU and memory and tune only after security review. TOTP replay is prevented by an atomic last-step update in the same PostgreSQL statement as session creation/audit. Rate limit is fixed-window bounded buckets (5/15 min per identifier bucket and global 120/min), with possible collisions and denial-of-service tradeoff. Add edge/request concurrency limits if supported. Review failed-attempt monitoring, password breach checks, administrator recovery dual control, browser security headers and page protection before release. CI test fixture validates SQL using isolated PostgreSQL only; real Hosting UAT remains mandatory. No production migration, credentials, enrollment, merge or deployment is claimed.
