# Wave 02 — Native CAMS integration consolidation
Receiver previously accepted managed Hostinger but Finance Inbox required local mode. Both now use a shared fail-closed database runtime classifier. Inbox read requires enabled docking, authenticated non-preview Finance/Approver role, approved whole-entity Finance assignment, configured entity and source tenant; receipts filtered by both keys. Native POST remains disabled: existing legacy endpoint combines approval and posting and must not be exposed on Hostinger. Separate independent maker/checker/poster commands, actual CAMS staging roundtrip and approval UI remain release blockers. No database migration or release flag enabled. Tests are technical source/contract checks, not live acceptance.
