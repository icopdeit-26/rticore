# Hostinger native runtime candidate
Set RTICORE_RUNTIME=hostinger and external DATABASE_URL (or POSTGRES_URL), RTICORE_ACCESS_TEAM_DOMAIN and RTICORE_ACCESS_AUD in Hostinger secure environment. Keep RTICORE_LOCAL_MODE unset. Domain must be protected by authorized Cloudflare Access application, including API routes; direct origin cannot authenticate without verified JWT. Provision schema/triggers and active authorized members separately through reviewed migration and backup. No default accounts or demo fallback. Native runtime deliberately skips request-time DDL. PostgreSQL batch uses dedicated pool client and rollback. Verify valid/expired/forged JWT, inactive membership, atomic rollback, finance reconciliation and exact SHA CI before release. No live configuration or deployment performed. Login CTA depends on actual Access protection; if absent, configure it before release.
